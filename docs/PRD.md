# itsmegram - Instagram AI Analyzer

## 📋 개요

itsmegram은 사용자의 인스타그램 계정을 AI로 분석하여 개인화된 리포트를 생성하는 웹 애플리케이션입니다.

---

## 🎯 목표

- 사용자의 인스타그램 활동을 AI로 분석하여 인사이트 제공
- 마케팅 페이지를 통해 유입 확보
- 생성된 리포트를 인스타그램 스토리로 공유 가능하도록 지원

---

## 📐 기술 스택

| 구분 | 기술 |
|------|------|
| Frontend | Next.js (Latest) |
| Backend | Python |
| 실행 | `npm start`로 프론트/백엔드 동시 실행 |

## 📄 페이지 구성

### 1. 홈 페이지 (`/`)

#### 기능
- 인스타그램 username 입력 폼
- itsmegram 서비스 소개

#### UI 구성
- Hero 섹션: 서비스 타이틀 및 간략한 설명
- Username 입력 폼
- 기능 소개 카드 (3-4개)

#### 입력값
- 인스타그램 username (예: `username`)

---

### 2. 마케팅 페이지 (`/marketing`)

#### 목적
- 실제 고객 유입용 랜딩 페이지
- 획기적이고 시각적으로 매력적인 디자인

#### UI/UX 요구사항
- 모던하고 세련된 디자인
- 인터랙티브 요소 포함
- 모바일 최적화
- 주요 기능 하이라이트
- CTA (Call to Action) 버튼

#### 섹션 구성
1. Hero 섹션 - 임팩트 있는 타이틀
2. 기능 소개 섹션
3. 리포트 미리보기/데모
4. 사용 방법
5. CTA 섹션

---

### 3. 리포트 결과 페이지 (`/report`)

#### 기능
- AI 분석 결과를 이미지 형태로 표시
- 공유/저장 기능 제공

#### 리포트 구성

##### 1️⃣ 기본 활동 지표
- 평균 좋아요
- 참여율 (Engagement Rate)
- 게시물 유형 비율 (피드 / 릴스 / 스토리)

##### 2️⃣ 콘텐츠 성향 분석
- 주요 콘텐츠 카테고리 (여행, 패션, 개발, 음식 등)
- 시각적 스타일 (톤, 색감, 구도)
- 텍스트 스타일 (감성적, 정보형, 유머형 등)
- 해시태그 사용 패턴

##### 3️⃣ 관심사 및 라이프스타일 추정
- 자주 등장하는 장소/브랜드
- 활동 패턴 (야외활동, 실내활동 등)
- 소비 성향 (브랜드 선호도 등)

##### 4️⃣ 성격/이미지 추정 (간접 분석)
- 외향/내향 경향
- 자기표현 강도
- 커뮤니케이션 방식 (공감형, 정보제공형, 자기중심형 등)

##### 5️⃣ 네트워크 특징
- 팔로워 대비 참여율
- 상호작용 계정 유형
- 커뮤니티 중심 vs 개인 브랜딩 중심

##### 6️⃣ 성장 가능성 분석
- 최근 성장 추이
- 콘텐츠 일관성
- 확장 가능 카테고리 제안

#### 리포트 작성 가이드라인
- 수치 + 해석을 함께 제시
- 추정 표현 사용 ("~로 보입니다")
- 핵심 5~7줄 요약 구조 유지

## 🔧 기능 명세

### 1. 인스타그랍 분석 기능

#### 입력
- 인스타그램 username

#### 처리 과정
1. 인스타그램 프로필 데이터 수집
2. 게시물 콘텐츠 분석 (이미지, 텍스트, 해시태그)
3. AI 모델을 통한 분석 및 인사이트 추출
4. 리포트 생성

#### 출력
- 구조화된 분석 리포트 (JSON)
- 시각화된 리포트 이미지

### 2. 리포트 공유 기능

#### 우선순위 1: 인스타그램 스토리 공유
- Instagram Stories API 연동
- 스토리 형식에 최적화된 이미지 생성 (9:16 비율)

#### 우선순위 2: 이미지 저장
- 리포트를 PNG/JPG로 다운로드
- HTML2Canvas 또는 Server-side 렌더링

---

## 🎨 디자인 가이드라인

### 브랜드 컬러
- Primary: Instagram 그라데이션 (병아리색 → 주황 → 분홍 → 복숭아)
- Background: 흰색 또는 연한 그레이
- Text: 다크 그레이/블랙

### 리포트 디자인
- 인스타그램 스토리 친화적 (1080x1920)
- 깔끔하고 현대적인 레이아웃
- 아이콘과 인포그래픽 활용

## 🚀 개발 요구사항

### 프론트엔드 (Next.js)
- App Router 사용
- TypeScript
- Tailwind CSS (스타일링)
- 반응형 디자인

### 백엔드 (Python)
- FastAPI
- Instagram 데이터 수집 API
- AI 분석 엔진 (Moonshot ai API)
- 이미지 생성/렌더링

### 실행 설정
```json
{
  "scripts": {
    "start": "concurrently \"npm run frontend\" \"npm run backend\"",
    "frontend": "next dev",
    "backend": "python backend/app.py"
  }
}
```

## ⚠️ 제약사항

1. **로그인 없음**: 사용자 인증 시스템 미구현 (누구나 사용 가능)
2. **공개 계정만 지원**: 비공개 계정 분석 불가
3. **API 제한**: 인스타그램 API 호출 한도 고려
4. **개인정보 보호**: 수집된 데이터는 분석 후 즉시 폐기
